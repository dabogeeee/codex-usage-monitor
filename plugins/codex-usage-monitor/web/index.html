切换聊天与指标说明

“最近活动”跟随最新产生 token 记录的普通聊天。桌面端切换到没有新活动的聊天时，请在上方选择聊天；插件无法读取桌面端的选中状态。

缓存命中率是最近一次请求的缓存输入与总输入之比；累计命中率按输入 token 加权。0% 是确实未命中，— 表示没有可用数据。

上下文占用是最近请求的输入加输出与日志中有效上下文上限之比。它是估算，生成期间及压缩后可能与原生界面存在差异。
