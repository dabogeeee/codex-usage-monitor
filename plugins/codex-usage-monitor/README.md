# Codex 用量面板

在新聊天中输入“打开 Codex 用量面板”。工具返回的本机地址可以用 Codex 的 `open_in_codex` 浏览器工具在右侧打开；支持 MCP Apps 的宿主也可加载插件 UI 资源。

本机 tokens 每 10 秒刷新，官方额度每 60 秒刷新。Plus 显示 5 小时与一周；Pro 默认一周。统计来源可切换“本机实时”和“账号官方”，官方数据可能延迟。

按聊天显示缓存命中率，以及最近请求 tokens 与日志有效上下文上限之比。上下文是估算，不是累计 tokens 与上限的比值。

“最近活动”仅跟随最新产生用量记录的聊天，不能读取 Codex 桌面端选中状态。切换到没有新活动的聊天时，请在面板手动选择。这个面板不会向原生固定侧栏注入数字。

运行要求：Python 3.9+、已登录的 Codex CLI。运行 `python3 server.py --serve --open` 可直接在默认浏览器打开；服务退出后面板停止。只在本机运行，不上传聊天正文，不需要 API Key。
