# Codex 用量面板

原生 SwiftUI/AppKit 悬浮面板，与菜单栏入口一起随 Codex 启动显示。也可以在新聊天中输入“打开 Codex 用量面板”，工具会打开已安装的原生应用。

主题支持跟随系统、浅色、深色，标题栏同步切换并保存选择。面板可以置顶、拖动、调整大小；关闭窗口后仍可从菜单栏重新打开。

本机 tokens 每 10 秒刷新，官方额度每 60 秒刷新。Plus 显示 5 小时与一周；Pro 默认一周。统计来源可切换“本机实时”和“账号官方”，官方数据可能延迟。

按聊天显示缓存命中率，以及最近请求 tokens 与日志有效上下文上限之比。上下文是估算，不是累计 tokens 与上限的比值。

“最近活动”仅跟随最新产生用量记录的聊天，不能读取 Codex 桌面端选中状态。切换到没有新活动的聊天时，请在面板手动选择。这个面板不会向原生固定侧栏注入数字。

运行要求：Apple Silicon Mac、macOS 14+、Python 3.9+、已登录的 Codex CLI。独立原生界面通过进程管道读取统计，不使用浏览器或 HTTP 服务，不上传聊天正文，不需要 API Key。

菜单栏顶部仅显示剩余额度，展开“用量与所选聊天”查看 UUID、日 / 周 / 月 / 累计 tokens 和各项比例，并复制所选聊天 UUID。指标来自最近活动或面板手动选择的聊天，不代表 Codex 桌面端选中状态。
